# 🎂 Sitio de cumpleaños

Sitio web estático listo para publicar con GitHub Pages.

## Personalización rápida

Abre `index.html` y cambia:

- `PERSONA ESPECIAL` → nombre de la persona.
- `TU NOMBRE` → tu nombre.
- Los textos de la carta.
- Los textos debajo de las fotografías.

### Fotos

Coloca tus imágenes en `img/` y llámalas:

- `foto1.jpg`
- `foto2.jpg`
- `foto3.jpg`
- `foto4.jpg`
- `foto5.jpg`

También puedes cambiar los nombres directamente en `index.html`.

### Música

Coloca una canción llamada `cancion.mp3` dentro de `audio/`.

**Nota:** usa música que tengas derecho a utilizar. Algunos navegadores no permiten reproducción automática hasta que el usuario interactúa con la página.

## Publicar en GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo `cumpleanos`.
2. Sube todos los archivos y carpetas de este proyecto.
3. Ve a `Settings` → `Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Selecciona `main` y `/ (root)`.
6. Guarda.
7. GitHub generará una URL parecida a:
   `https://TUUSUARIO.github.io/cumpleanos/`

Esa URL será la que usarás para crear el código QR.
